# 家庭成员使用说明书

适用于管理员已经部署好的独立实例。本文不包含任何真实账号或进入链接。

### 1. 第一次进入

1. 点管理员私下发给你的**完整专属链接**，直接进入日记。
2. 不需要注册平台账号，也不需要设置家人密码。这不是微信身份登录；在微信中点开只是使用微信内的浏览器。
3. 每个人使用自己的链接。链接代表你的身份，不要与别人混用或公开转发。
4. 如果部署者使用 CloudBase 测试域名，可能先出现平台的页面访问说明；这与应用的登录页不同。

退出登录、换设备或浏览器数据被清理后，可以再次打开原来的专属链接。也可以把完整链接粘到登录页的“家人通行码或专属链接”中，点“打开我们的日记”。链接失效或找不到时，请找管理员。

### 2. 添加到手机桌面

先保留自己的原始专属链接。桌面图标的名称**可以自由填写**，只影响自己手机上的图标名字，不会修改账号名或网站名称。

#### 苹果手机：使用 Safari

1. 复制完整专属链接，打开手机自带的 Safari 浏览器，粘贴到地址栏后进入。
2. 点“分享／共享”按钮，通常是一个方框加向上箭头；部分布局要先打开地址栏旁的页面菜单。
3. 在菜单中向下找“添加到主屏幕”。未看到时，可在底部“编辑操作”中查找。
4. 填写喜欢的图标名称。如果出现“作为网页 App 打开”，可开启，再点“添加”。
5. 以后从手机桌面点该图标进入。

#### 安卓手机：使用常用浏览器

1. 复制完整专属链接，在手机浏览器的地址栏中粘贴并进入。
2. 点菜单按钮，常见样式是三个点或三条横线。
3. 找“添加到桌面”“添加到主屏幕”或“创建快捷方式”，按提示确认。名称可以自己填写。
4. Chrome 部分版本的入口是“安装并创建快捷方式 → 创建快捷方式”。其他品牌浏览器的名称和位置可能不同。
5. 找不到添加入口时，先把网页加入浏览器的收藏或书签，以后从收藏打开。

如果桌面图标第一次打开后要求登录，把保留的专属链接粘到家人进入框即可。微信、Safari、安卓浏览器和桌面网页入口的登录状态可能不互通，建议固定使用同一个入口。

操作入口参考：[苹果官方说明](https://support.apple.com/zh-cn/guide/iphone/iphea86e5236/ios)、[Chrome 官方说明](https://support.google.com/chrome/answer/15085120?co=GENIE.Platform%3DAndroid&hl=zh-Hans)。

### 3. 浏览最近的日子

| 栏目 | 显示内容 |
| --- | --- |
| 慢慢翻 | 当前账号有权查看的全部未收起记录，包括自己的私密日记 |
| 分享的日子 | 其他家人发布且你有权查看的记录；不包括任何自己发布的内容 |
| 我的记录 | 自己发布的未收起记录，包括私密和已经分享的内容 |

切换栏目只是筛选，不改变访问权限。其他人的“仅自己”记录不会因为切换栏目而变得可见。

首页的两个时钟显示部署者配置的固定地点，而不是随查看者所在地变化；会显示日期，并按所选时区处理夏令时。太阳和月亮表示大致昼夜，不是天气或实际日出日落预报。

点首页的刷新按钮可重新读取记录。网站功能更新通常需要重新加载网页。页面可见时约每分钟轻量检查新分享和收到的新回复，返回页面时也会检查；提示不会自动刷新正在阅读的列表。

### 4. 写一则日记

1. 点“记一刻”。
2. 输入生活小记，最多 5000 字符；可以不写文字，只添加照片。
3. 点“添张照片”，每篇最多 3 张。照片会自动压缩，原照片太大或浏览器不能解码时会提示换图或裁剪。
4. 选择分享范围和回应方式。
5. 点底部的“收进我的日记”“分享这一刻”或编辑时的“保存修改”。成功提示出现后，才完成保存。

**草稿会自动保存在当前账号的这台设备上。** 刷新后可到「记一刻」继续，不会自动发布，也不会同步到其他设备。浏览器清理网站数据或本机空间不足时草稿可能丢失，请留意保存提示；重要文字仍建议另存。自动压缩的图片不等于原图备份。

#### 分享范围

| 选择 | 谁能看 |
| --- | --- |
| 仅自己 | 只有发布者自己；这是新日记的默认选择 |
| 全家 | 此实例中所有当前获准进入的家人 |
| 指定家人 | 发布者自己，以及勾选的家人；必须至少选择一人 |

日记下面的留言和图片沿用原日记的查看范围。修改分享范围后，留言的可见范围也跟随变化。

#### 回应方式

| 选择 | 家人可以怎么回应 |
| --- | --- |
| 只收抱抱 | 可以留下拥抱，不能添加文字或图片留言 |
| 欢迎留言 | 可以拥抱、写留言或发留言图片 |
| 想听听建议 | 同样允许留言，另外表达愿意听建议的意愿 |

后两种方式的操作能力相同，区别在于对家人的表达。切换到“只收抱抱”会关闭新增留言入口，已有留言仍保留。

### 5. 抱抱、留言与看大图

- 点“抱抱”表达关心；再点一次可以取消自己留下的抱抱。
- 允许留言时，点“留句话”，输入最多 1000 字符，或点“附一张图片”。一条留言最多附 1 张图片，也可以只发图片。
- 点“留下这条留言”发送。留言会显示留言者的名字，若你设置了备注，则使用你的备注。
- 点帖子中的任意照片，从这一张开始看大图；手机左右滑动切换同一帖的照片。
- 电脑可以点左右箭头，或使用键盘左右方向键；点关闭按钮或按 Esc 退出。
- 留言图片也能点开查看，但单张留言图片不会混入其他帖子的相册。

**有站内未读提示，没有锁屏推送。** 新分享、自己发布或评论过的帖子有新评论时会提示；点开帖子后，自动清除这篇已加载内容对应的提醒，其他帖子不受影响，之后的新评论仍会提醒。抱抱只显示是否有人留下拥抱，暂不显示人数或具体是谁；“抱抱已留下”表示你自己已经点过。

### 6. 编辑、收起、恢复和彻底删除

只有发布者可以编辑自己的日记。点日记右上角“编辑”，调整文字、照片、分享对象或回应方式，再保存。

不想继续展示时，在编辑页点**“收起这条记录”**：

- 它会从首页和回忆中消失，原来能看它的家人也不能继续查看。
- 底部的“撤销”可以立即恢复。
- 关闭提示或刷新后，仍可在“我们 → 回收站”找到。以前收起的记录也会出现。

回收站只显示自己的记录，其他家人不能查看或恢复：

| 操作 | 结果 |
| --- | --- |
| 恢复记录 | 保留照片、留言与拥抱，回到原来的分享范围；原本分享给家人的内容会重新对他们可见 |
| 彻底删除 | 再次确认后，删除云端日记、相关留言和拥抱，并清理不再被其他记录使用的照片；不能在网站恢复 |
| 重试清理 | 日记已删除但照片清理失败时出现；重试完成剩余的云端照片清理 |

同一照片若仍被另一条记录使用，会保留那份照片。彻底删除不会修改任何人已经下载或导出的文件，也不代表清除了云平台可能持有的独立备份。

### 7. 翻看回忆

进入“回忆”，按月份筛选，也可以点“偶遇一段回忆”，随机打开当前账号可见的一则日记。点回忆卡片可阅读完整内容。收起和彻底删除的记录不会出现在这里。

### 8. 名字、头像、个人备注

进入“我们 → 我的头像和名字”：

- **改名字**：填写后点“保存名字”。没有给你设置备注的家人，会看到你自己的名字。
- **换头像**：选照片后可拖动位置，用滑块或加减按钮缩放，对准圆框，再点“使用这个头像”。可以重新居中、取消，或恢复默认头像。
- 每个人只能修改自己的名字和头像，同一个账号在不同设备上使用同一份资料。

在“在这里的家人”中，点“设置备注／修改备注”：

- 给对方填写自己习惯的称呼，最多 24 字符。
- 备注只对设置者显示，同一账号的不同设备会同步；不会替对方修改名字。
- 备注用于日记作者、留言者、回忆和分享对象等位置。
- 留空并保存，就恢复显示对方自己的名字。

三种称呼相互独立：

| 称呼 | 由谁设置 | 用途 |
| --- | --- | --- |
| 访问管理的身份标签 | 管理员邀请时填写 | 管理员识别成员和对应链接；不会随个人改名变化 |
| 自己的名字 | 成员自己修改 | 没有私人备注时，全家看到的名字 |
| 给别人的备注 | 每个查看者各自设置 | 只有设置者看到的个人称呼 |

新成员的初始名字沿用邀请时的身份标签。修改名字、头像和备注都不会改变成员身份或专属链接。

### 9. 大字模式和导出

进入“我们 → 用得舒服一点”：

- 开启“大字模式”可放大文字和控件。这个偏好保存在当前浏览器，换设备后可再开启。
- 在“导出格式”选择 PDF 或 JSON，再点对应的导出按钮。文件会保存或交给浏览器下载，手机上可从浏览器下载记录或文件管理中查找。

| 格式 | 适合什么用途 |
| --- | --- |
| PDF 家庭相册 | 阅读、分享给有权限的家人、保存或打印；包括日期、作者、正文、照片和留言图片，并自动分页 |
| JSON 完整备份 | 保存记录、图片和本人回收站；可在「我们 → 恢复 JSON 备份」预览后恢复本人记录 |

PDF 导出的是**当前账号有权查看的全部未收起记录**，JSON 还包含本人的回收站；不跟随首页栏目、已加载页数或回忆月份筛选。导出的文件包含私人内容，请妥善保管，不要作为源码附件上传 GitHub。

完整的功能介绍、管理员操作和部署指南见 [README](../README.md)。

### 保存、翻页与恢复的新说明

- 网络中断后重试同一次保存，不会重复发布；多设备同时编辑发生冲突时保留草稿并提示，不会静默覆盖新修改。可查看最新记录，或将草稿另存为仅自己可见的新记录。
- 首页、回忆和回收站按页读取。回忆月份、正文搜索、家人筛选和收藏筛选覆盖所有有权查看的历史；随机回忆从当前已显示的匹配记录中抽选。
- 新版个人 JSON 可从「我们 → 恢复 JSON 备份」导入，先显示数量，确认后恢复本人的记录；不覆盖已有内容。
- 管理员可检查并清理云端不再使用的旧照片，正在使用、回收站引用以及最近24小时内的照片会保留。

完整恢复范围和管理员加密整站备份工具见[备份与恢复说明](BACKUP_AND_RESTORE.md)。

### 阅读与回忆使用更新

1. 首页直接进入简洁的日记入口，欢迎插画收进「看看我们的日夜小窗」。
2. 抱抱、留言和收藏只更新对应帖子，保留已加载记录与阅读位置。
3. 日记日期、年份和月份筛选统一按中国时间；双地时钟依然按各自的时区显示。
4. 回忆中可按完整历史月份、家人、正文关键词查找，支持组合「只看我的收藏」；收藏跨设备保存在本人账号里，其他家人不会看到你的收藏列表。
5. 图片失败时点「重新加载这张」，只重试该图片。较慢的读取会说明正在等待或重试，已有内容继续保留。
6. 第一次启用新内容提示时从当下建立基准，不把全部历史当作未读。以后页面可见时约每分钟、返回页面时轻量检查；内容包括有权看到的新分享和其他人给自己发布或评论过的帖子的新评论。
7. 提示中的「有空看看」会列出最近30项，可打开较早的帖子；点开帖子并成功加载后自动清除这篇已有的提示，已读状态同步到同一账号的其他设备；「这些提示我看过了」可一次清除当前账号截至本次检查的全部提示，不删除日记，也不向家人发送已读回执。之后新到的内容仍会继续提示。
