# 家庭成员使用说明

1. 点管理员私下发给你的专属链接进入，不用注册平台账号。不要混用或公开链接。
2. 可在手机浏览器里收藏网页或添加到主屏幕，图标名称可自定。iPhone 使用 Safari 的分享菜单；安卓在浏览器菜单中寻找添加到桌面或创建快捷方式。不同版本名称可能不同。
3. 从图标进入若要求登录，将自己的完整专属链接粘到家人进入框。换设备仍使用原链接。
4. 最近的日子：慢慢翻显示全部有权查看的记录；分享的日子只显示其他人的分享；我的记录只显示自己发布的内容。
5. 记一刻：文字与最多三张照片，选择仅自己、全家或指定家人，再保存。回应模式可选只收抱抱、欢迎留言或想听建议。
6. 点抱抱可以表达关心，再点取消。允许留言的记录可附一张照片，也可只发照片。原日记的查看权限同时约束留言。
7. 点图片看大图，同一帖可左右滑动；电脑也能点箭头或用方向键。
8. 编辑只允许修改自己的记录。收起后到我们里的回收站恢复；彻底删除需要再次确认。失败的云端照片清理可重试。
9. 回忆支持月份筛选和随机翻看。
10. 我们里可修改自己的名字、头像；头像可拖动缩放并按圆框定位。对其他家人的备注只在自己的账号内显示并跨设备同步。
11. 管理员访问管理里的身份标签不会随个人改名而改变。
12. 大字模式保存在当前浏览器；PDF 相册适合阅读，JSON 备份用于留存，目前不支持导入。导出只包括当前账号有权看到的记录。

需要联网。网站不自动实时刷新，也没有手机通知、微信提醒、未读红点或抱抱人数显示；刷新后查看新内容。保存失败时先保留文字和原照片。
