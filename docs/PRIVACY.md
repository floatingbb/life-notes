# 分享源码与家庭实例的隔离

这个仓库是全新整理的源码副本，不包含原开发工作目录或原站点提交历史。

## 发布包里有什么

通用前后端代码、空白变量模板、空库迁移、合成数据测试、使用和部署说明。测试在内存中创建虚构成员、文字和图片引用，不读取任何在线家庭实例。

## 不应提交的内容

- 真实成员、备注、日记、照片、评论、导出备份或页面截图。
- 管理员密码或其哈希、会话密钥、初始化令牌、成员进入链接、API Key、云凭据。
- 任何正在使用的环境 ID、站点域名、账号配置或部署日志。
- `.env`、`.data/`、`node_modules/`、`dist/`、本机配置目录和历史工具输出。

`.gitignore`、发布清单和 `npm run check:privacy` 共同防止误提交。自动检查不能证明绝对没有秘密；发布前仍应检查提交差异。

## 构建和上线是分开的

`npm run build` 只构建本地文件，不调用云平台，不继承现有项目配置，不执行数据库迁移。Actions 也不会部署。

配置模板没有可用凭据。后端必须显式配置自己的新环境、地域和服务端密钥才能启动。前端配置只调整显示偏好。

## 将来公开前

检查仓库所有提交，而不只是当前文件；确认没有把真实配置、数据或网址加入历史。不要为了展示功能粘贴家人的照片或真实页面截图。若曾提交有效密钥，应先撤销并重新生成，删除文件不能消除已泄露的历史副本。

仓库可见性应由维护者在检查后自行决定。本仓库不会自行更改可见性。
