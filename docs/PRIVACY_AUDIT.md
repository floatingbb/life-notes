## 如何避免与其他实例混淆

1. 下载源码不会连接任何已经存在的日记站点。
2. 管理员必须新建自己的环境、私有图片桶，配置自己的网址、API Key、会话密钥和初始化令牌。
3. `CLOUDBASE_ENV_ID` 的占位内容不能直接使用；`SITE_ORIGIN` 的示例域名也不能直接使用。
4. 初始化页面没有预设密码，家人链接只在该独立实例邀请成员后生成。
5. 界面中的地点显示可在 `src/site-config.ts` 自定义；示例显示不代表任何真实家庭地址。
6. GitHub Actions 只检查代码，不部署到网站，也不读取任何生产凭据。

这份报告描述检查当时的代码和历史，不保证后续提交始终合规。后续修改配置、添加截图、上传备份或公开仓库前，仍应再次检查；不要把真实敏感值写入报告本身。
