# 日子之间 · Life Notes

**为异地家人设计的私密生活日记：各自过日子，也在这里相遇。**

可以写几句话、分享照片、给家人留个拥抱，也可以把一段心情先留给自己。没有打卡和已读提醒，不要求及时回复。

这是适合手机和电脑浏览器使用的网页应用，不是微信原生小程序。家庭成员不需要 ChatGPT、GitHub 或腾讯云账号，使用管理员私下发给自己的专属链接进入即可。

> **源码与家庭数据分开。** 本仓库只提供通用程序、空白配置模板、合成数据测试和说明书，不包含任何家庭的账号、日记、照片、进入链接、生产网址或云凭据。下载和构建不会连接或修改其他人的在线实例。要使用它，请部署自己的版本。

**没有默认管理员密码，也没有可直接登录的预设站点。** 文档中的 `https://your-site.example` 只是不对应实际服务的占位示例。部署者必须填写自己的 `SITE_ORIGIN`、新环境及新密钥，生成自己的初始化令牌，并在首次进入时自行设置管理员密码。示例地址和占位环境不能直接启动后端。测试中的口令仅用于内存合成测试，不是任何家庭的登录密码。

| 编辑与回收站 | 编辑自己的日记、收起、撤销收起、恢复、确认彻底删除 |

| 导出 | PDF 阅读相册、JSON 数据备份，包含可见日记与留言照片 |
| 访问管理 | 管理员邀请、查看与补存链接、重新生成、撤销访问 |

## 家人使用说明书

### 1. 第一次进入

1. 点管理员私下发给你的**完整专属链接**，直接进入日记。
2. 不需要注册平台账号，也不需要设置家人密码。这不是微信身份登录；在微信中点开只是使用微信内的浏览器。
3. 每个人使用自己的链接。链接代表你的身份，不要与别人混用或公开转发。
4. 如果部署者使用 CloudBase 测试域名，可能先出现平台的页面访问说明；这与应用的登录页不同。

退出登录、换设备或浏览器数据被清理后，可以再次打开原来的专属链接。也可以把完整链接粘到登录页的“家人通行码或专属链接”中，点“打开我们的日记”。链接失效或找不到时，请找管理员。

### 2. 添加到手机桌面

先保留自己的原始专属链接。桌面图标的名称**可以自由填写**，只影响自己手机上的图标名字，不会修改账号名或网站名称。

#### 苹果手机：使用 Safari

1. 复制完整专属链接，打开手机自带的 Safari 浏览器，粘贴到地址栏后进入。
2. 点“分享／共享”按钮，通常是一个方框加向上箭头；部分布局要先打开地址栏旁的页面菜单。
3. 在菜单中向下找“添加到主屏幕”。未看到时，可在底部“编辑操作”中查找。
4. 填写喜欢的图标名称。如果出现“作为网页 App 打开”，可开启，再点“添加”。
5. 以后从手机桌面点该图标进入。

#### 安卓手机：使用常用浏览器

1. 复制完整专属链接，在手机浏览器的地址栏中粘贴并进入。
2. 点菜单按钮，常见样式是三个点或三条横线。
3. 找“添加到桌面”“添加到主屏幕”或“创建快捷方式”，按提示确认。名称可以自己填写。
4. Chrome 部分版本的入口是“安装并创建快捷方式 → 创建快捷方式”。其他品牌浏览器的名称和位置可能不同。
5. 找不到添加入口时，先把网页加入浏览器的收藏或书签，以后从收藏打开。

如果桌面图标第一次打开后要求登录，把保留的专属链接粘到家人进入框即可。微信、Safari、安卓浏览器和桌面网页入口的登录状态可能不互通，建议固定使用同一个入口。

操作入口参考：[苹果官方说明](https://support.apple.com/zh-cn/guide/iphone/iphea86e5236/ios)、[Chrome 官方说明](https://support.google.com/chrome/answer/15085120?co=GENIE.Platform%3DAndroid&hl=zh-Hans)。

### 3. 浏览最近的日子

| 栏目 | 显示内容 |
| --- | --- |
| 慢慢翻 | 当前账号有权查看的全部未收起记录，包括自己的私密日记 |
| 分享的日子 | 其他家人发布且你有权查看的记录；不包括任何自己发布的内容 |
| 我的记录 | 自己发布的未收起记录，包括私密和已经分享的内容 |

切换栏目只是筛选，不改变访问权限。其他人的“仅自己”记录不会因为切换栏目而变得可见。

首页的两个时钟显示部署者配置的固定地点，而不是随查看者所在地变化；会显示日期，并按所选时区处理夏令时。太阳和月亮表示大致昼夜，不是天气或实际日出日落预报。

点首页的刷新按钮可重新读取记录。网站功能更新通常需要重新加载网页。页面可见时约每分钟轻量检查新分享和收到的新回复，返回页面时也会检查；提示不会自动刷新正在阅读的列表。

### 4. 写一则日记

1. 点“记一刻”。
2. 输入生活小记，最多 5000 字符；可以不写文字，只添加照片。
3. 点“添张照片”，每篇最多 3 张。照片会自动压缩，原照片太大或浏览器不能解码时会提示换图或裁剪。
4. 选择分享范围和回应方式。
5. 点底部的“收进我的日记”“分享这一刻”或编辑时的“保存修改”。成功提示出现后，才完成保存。

**草稿会自动保存在当前账号的这台设备上。** 刷新后可到「记一刻」继续，不会自动发布，也不会同步到其他设备。浏览器清理网站数据或本机空间不足时草稿可能丢失，请留意保存提示；重要文字仍建议另存。自动压缩的图片不等于原图备份。

#### 分享范围

| 选择 | 谁能看 |
| --- | --- |
| 仅自己 | 只有发布者自己；这是新日记的默认选择 |
| 全家 | 此实例中所有当前获准进入的家人 |
| 指定家人 | 发布者自己，以及勾选的家人；必须至少选择一人 |

日记下面的留言和图片沿用原日记的查看范围。修改分享范围后，留言的可见范围也跟随变化。

#### 回应方式

| 选择 | 家人可以怎么回应 |
| --- | --- |
| 只收抱抱 | 可以留下拥抱，不能添加文字或图片留言 |
| 欢迎留言 | 可以拥抱、写留言或发留言图片 |
| 想听听建议 | 同样允许留言，另外表达愿意听建议的意愿 |

后两种方式的操作能力相同，区别在于对家人的表达。切换到“只收抱抱”会关闭新增留言入口，已有留言仍保留。

### 5. 抱抱、留言与看大图

- 点“抱抱”表达关心；再点一次可以取消自己留下的抱抱。
- 允许留言时，点“留句话”，输入最多 1000 字符，或点“附一张图片”。一条留言最多附 1 张图片，也可以只发图片。
- 点“留下这条留言”发送。留言会显示留言者的名字，若你设置了备注，则使用你的备注。
- 点帖子中的任意照片，从这一张开始看大图；手机左右滑动切换同一帖的照片。
- 电脑可以点左右箭头，或使用键盘左右方向键；点关闭按钮或按 Esc 退出。
- 留言图片也能点开查看，但单张留言图片不会混入其他帖子的相册。

**目前没有消息推送或未读提示。** 收到评论后需刷新查看。抱抱只显示是否有人留下拥抱，暂不显示人数或具体是谁；“抱抱已留下”表示你自己已经点过。

### 6. 编辑、收起、恢复和彻底删除

只有发布者可以编辑自己的日记。点日记右上角“编辑”，调整文字、照片、分享对象或回应方式，再保存。

不想继续展示时，在编辑页点**“收起这条记录”**：

- 它会从首页和回忆中消失，原来能看它的家人也不能继续查看。
- 底部的“撤销”可以立即恢复。
- 关闭提示或刷新后，仍可在“我们 → 回收站”找到。以前收起的记录也会出现。

回收站只显示自己的记录，其他家人不能查看或恢复：

| 操作 | 结果 |
| --- | --- |
| 恢复记录 | 保留照片、留言与拥抱，回到原来的分享范围；原本分享给家人的内容会重新对他们可见 |
| 彻底删除 | 再次确认后，删除云端日记、相关留言和拥抱，并清理不再被其他记录使用的照片；不能在网站恢复 |
| 重试清理 | 日记已删除但照片清理失败时出现；重试完成剩余的云端照片清理 |

同一照片若仍被另一条记录使用，会保留那份照片。彻底删除不会修改任何人已经下载或导出的文件，也不代表清除了云平台可能持有的独立备份。

### 7. 翻看回忆

进入“回忆”，按月份筛选，也可以点“偶遇一段回忆”，随机打开当前账号可见的一则日记。点回忆卡片可阅读完整内容。收起和彻底删除的记录不会出现在这里。

### 8. 名字、头像、个人备注

进入“我们 → 我的头像和名字”：

- **改名字**：填写后点“保存名字”。没有给你设置备注的家人，会看到你自己的名字。
- **换头像**：选照片后可拖动位置，用滑块或加减按钮缩放，对准圆框，再点“使用这个头像”。可以重新居中、取消，或恢复默认头像。
- 每个人只能修改自己的名字和头像，同一个账号在不同设备上使用同一份资料。

在“在这里的家人”中，点“设置备注／修改备注”：

- 给对方填写自己习惯的称呼，最多 24 字符。
- 备注只对设置者显示，同一账号的不同设备会同步；不会替对方修改名字。
- 备注用于日记作者、留言者、回忆和分享对象等位置。
- 留空并保存，就恢复显示对方自己的名字。

三种称呼相互独立：

| 称呼 | 由谁设置 | 用途 |
| --- | --- | --- |
| 访问管理的身份标签 | 管理员邀请时填写 | 管理员识别成员和对应链接；不会随个人改名变化 |
| 自己的名字 | 成员自己修改 | 没有私人备注时，全家看到的名字 |
| 给别人的备注 | 每个查看者各自设置 | 只有设置者看到的个人称呼 |

新成员的初始名字沿用邀请时的身份标签。修改名字、头像和备注都不会改变成员身份或专属链接。

### 9. 大字模式和导出

进入“我们 → 用得舒服一点”：

- 开启“大字模式”可放大文字和控件。这个偏好保存在当前浏览器，换设备后可再开启。
- 在“导出格式”选择 PDF 或 JSON，再点对应的导出按钮。文件会保存或交给浏览器下载，手机上可从浏览器下载记录或文件管理中查找。

| 格式 | 适合什么用途 |
| --- | --- |
| PDF 家庭相册 | 阅读、分享给有权限的家人、保存或打印；包括日期、作者、正文、照片和留言图片，并自动分页 |
| JSON 完整备份 | 保存记录、图片和本人回收站；可在「我们 → 恢复 JSON 备份」预览后恢复本人记录 |

PDF 导出的是**当前账号有权查看的全部未收起记录**，JSON 还包含本人的回收站；不跟随首页栏目、已加载页数或回忆月份筛选。导出的文件包含私人内容，请妥善保管，不要作为源码附件上传 GitHub。

## 管理员使用说明书

### 首次设置

部署者先完成自己的云环境配置，再使用自己的初始化链接设置至少 12 位的管理员密码。初始化链接只用于第一次设置，不能发给家人。之后使用“管理员进入”和该密码登录。

### 邀请家人

1. 点页面顶部“邀请家人”。
2. 填写相对于自己的身份标签，例如“家人甲”。它也是新成员的初始名字。
3. 点“生成专属链接”，复制后私下发给本人。每位家人生成一条，目前一个实例最多支持 30 位活跃成员，包含管理员。
4. 新生成的链接按成员加密保存，之后可在该成员下点“查看专属链接”再次复制。

### 管理已有访问权限

| 操作 | 什么时候用 | 对原有内容的影响 |
| --- | --- | --- |
| 查看专属链接 | 对方找不到链接，需要再发一次 | 不改变链接或登录状态 |
| 补存原链接 | 从没有保存原链接的旧版升级后，手头仍有那条链接 | 核对链接归属再保存，不改变账号或链接 |
| 重新生成 | 找不到旧链接，或想让旧链接失效 | 需确认；保留该成员和日记，旧链接及当前登录设备失效，再把新链接发给本人 |
| 撤销并移除 | 不再允许该成员进入 | 从管理列表移除，旧链接和当前登录设备失效；不会自动删除其历史日记 |

身份标签不会被家人自行改名覆盖，管理页还会显示对方现在的名字，方便核对。旧版只存校验值的链接不能凭校验值还原；请补存或重新生成。

管理员在日记页面上同样受到记录查看范围限制，不能通过回收站查看其他人的私密或已收起记录。云端运维权限属于另一层边界，见 [SECURITY.md](SECURITY.md)。

## 常见问题

| 问题 | 说明 |
| --- | --- |
| 是微信登录吗？ | 不是。家人使用专属链接，管理员使用自己设置的密码 |
| 换设备会丢内容吗？ | 已保存的内容在云端；用同一身份进入即可查看，但页面需要刷新 |
| 添加桌面图标时名字能改吗？ | 可以，只改自己手机上的图标名称 |
| 家人发了内容为什么没变化？ | 页面会提示新分享和新回复，点击查看；也可手动刷新首页 |
| 新分享和新回复会提醒吗？ | 页面可见时约每分钟、返回页面时检查新分享及本人收到的新回复；使用站内提示，不发送微信或手机推送，也不向家人发送已读回执。首次启用从当前建立提示基准 |
| 抱抱有几个、谁点的能看到吗？ | 当前只显示是否有拥抱和自己是否点过，不显示人数或名单 |
| 保存失败怎么办？ | 先保留文字和原照片，不要立即刷新；检查网络、登录状态和提示，再重试 |
| 照片不能选择或读取？ | 大于 25MB 或浏览器不能解码时可能失败，尝试 JPG、PNG 或裁剪后的照片 |
| 为什么 JSON 不适合直接看？ | 它是数据备份格式；阅读请选择 PDF |
| 收起后别人还能看吗？ | 不能。自己的回收站可以预览和恢复 |
| 彻底删除后为什么还有清理提示？ | 记录已删除，但云端照片删除暂时失败；回收站会保留重试入口 |
| 网页能直接部署到 GitHub Pages 吗？ | 静态页面不能代替服务端权限、数据库和私有存储；完整功能需要自己的后端 |

## 当前限制

- 需要联网；没有离线使用、语音或视频。
- 没有手机推送、微信通知、自动刷新当前阅读内容或抱抱人数显示；新分享和本人收到的新回复使用可关闭的站内提示。
- 留言暂不提供单独编辑、单独删除或楼中楼回复。
- 新版 JSON 可恢复本人记录，导入后仅自己可见；PDF 适合阅读，不能作为恢复文件。旧版缺少账号标识的 JSON 需先从新版重新导出。
- 草稿仅保存在本机当前账号下；清理浏览器数据会丢失本机草稿。照片会压缩，不用于保留原图。
- 没有管理员密码自助找回功能。请维护者自行妥善保存密码、云配置及备份。
- 不承诺永久免费、无限容量或云服务可用性。需自行关注套餐额度、有效期和凭据到期日。

## 部署自己的版本

本仓库使用 React + TypeScript、Node.js 云函数、CloudBase PostgreSQL 和私有 pgstore 图片桶。前端只请求同域 `/api`，服务端凭据只配置在自己的云函数环境中。

### 安装、检查和构建

需要 Node.js 22.13 或更高版本：

```sh
npm ci --ignore-scripts
npm test
npm run check:privacy
npm run build
```

构建输出：

| 路径 | 用途 |
| --- | --- |
| `dist/public/` | 静态网页文件 |
| `dist/cloudfunctions/our-days-api/` | Node.js 云函数代码，入口 `index.main` |

**上述命令只在本地安装、测试和构建，不创建云资源、不执行迁移、不发布网站。** GitHub Actions 也只运行检查和构建，不含任何自动部署任务或生产密钥。

### 上线流程

1. 新建你自己的 CloudBase PostgreSQL 环境。
2. 执行仓库里的空库迁移，建立自己的空表、索引和权限。
3. 创建自己的私有 pgstore 图片桶。
4. 设置自己的站点根地址 `SITE_ORIGIN`、环境 ID、地域、服务端 API Key、随机会话密钥和初始化令牌。
5. 手动部署静态文件与云函数，配置 HTTPS 及同域 `/api` 路由。
6. 用自己的初始化链接设置管理员，再为自己的家人创建新链接。

完整步骤和变量表见 [部署说明书](docs/DEPLOYMENT.md)。未配置自己的环境时，后端会拒绝启动。不要复用其他人的环境、数据库、照片桶、密码哈希、会话密钥或备份。

### 修改两地时间

编辑 `src/site-config.ts`，填写显示标签和 IANA 时区。默认提供中国时间与 UTC 的通用示例，并未保留任何家庭的实际地点。重新构建、部署后生效。前端配置中不能放密码、密钥或专属链接。

## 隐私与安全边界

- 分享源码副本不包含任何在线实例的数据、凭据或部署绑定。
- 数据库启用 RLS；私有图片由服务端检查登录身份、原日记范围及收起状态后读取。
- 专属链接是身份凭证，服务端按成员加密保存；真实链接不应公开。
- 私人备注只返回给设置者；管理员访问标签与个人名字分开保存。
- 这不是端到端加密系统。拥有云端运维权限的维护者或云服务运营者可能接触数据。
- `.gitignore`、隐私扫描和 `PUBLICATION_MANIFEST.json` 用于降低误提交风险，不能代替人工检查。
- 公开仓库前，应检查所有提交历史，不只是当前文件。真实配置、家庭照片、截图和导出备份都不应上传。

进一步阅读：[隐私隔离说明](docs/PRIVACY.md)、[本次隐私复查说明](docs/PRIVACY_AUDIT.md)、[安全边界](SECURITY.md)。

### 保存、翻页与恢复的新说明

- 网络中断后重试同一次保存，不会重复发布；多设备同时编辑发生冲突时保留草稿并提示，不会静默覆盖新修改。可查看最新记录，或将草稿另存为仅自己可见的新记录。
- 首页、回忆和回收站按页读取。回忆月份、正文搜索、家人筛选和收藏筛选覆盖所有有权查看的历史；随机回忆从当前已显示的匹配记录中抽选。
- 新版个人 JSON 可从「我们 → 恢复 JSON 备份」导入，先显示数量，确认后恢复本人的记录；不覆盖已有内容。
- 管理员可检查并清理云端不再使用的旧照片，正在使用、回收站引用以及最近24小时内的照片会保留。

完整恢复范围和管理员加密整站备份工具见[备份与恢复说明](docs/BACKUP_AND_RESTORE.md)。

### 阅读与回忆使用更新

1. 首页直接进入简洁的日记入口，欢迎插画收进「看看我们的日夜小窗」。
2. 抱抱、留言和收藏只更新对应帖子，保留已加载记录与阅读位置。
3. 日记日期、年份和月份筛选统一按中国时间；双地时钟依然按各自的时区显示。
4. 回忆中可按完整历史月份、家人、正文关键词查找，支持组合「只看我的收藏」；收藏跨设备保存在本人账号里，其他家人不会看到你的收藏列表。
5. 图片失败时点「重新加载这张」，只重试该图片。较慢的读取会说明正在等待或重试，已有内容继续保留。
6. 第一次启用新内容提示时从当下建立基准，不把全部历史当作未读。以后页面可见时约每分钟、返回页面时轻量检查；内容包括有权看到的新分享和其他人给本人旧记录的新回复。
7. 提示中的「有空看看」会列出最近30项，可打开较早的帖子；「这些提示我看过了」清除当前账号截至本次检查的提示，不删除日记，也不向家人发送已读回执。之后新到的内容仍会继续提示。
