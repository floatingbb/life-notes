# 日子之间 · Life Notes

一个适合手机使用的私密家庭生活日记。异地的家人可以分享照片、文字和拥抱，有空再看，不需要及时回复。

> 这是可独立部署的通用源码，不是任何家庭的在线日记。仓库不附带现成账号、家庭数据、生产网址、云环境绑定或部署密钥。下载、构建和推送此仓库不会修改已有网站。

## 功能

- 每位家人独立的进入链接；管理员邀请、撤销、重新生成和复制已保存的链接。
- 固定的访问管理身份标签、可修改的个人名字、只有自己能看到的家人备注。
- 可拖动、缩放、圆框定位的头像裁剪。
- 日记文字与最多三张压缩照片；仅自己、全家、指定家人的访问范围。
- 只收抱抱、欢迎留言、想听建议；留言可附一张照片，也能只发图片。
- 帖子相册左右滑动、月份筛选、随机回忆、两地时钟、大字模式。
- 只看他人分享、自己的记录或全部有权查看的内容。
- 收起记录、个人回收站、恢复、二次确认彻底删除和云端照片清理重试。
- PDF 家庭相册和 JSON 数据备份，包含当前账号可见的日记、照片与留言图片。

目前没有手机推送、微信通知、未读红点或抱抱人数显示；没有语音、视频、离线模式和备份导入。显示新内容需要刷新。

## 技术与运行方式

React + TypeScript 前端，Node.js 云函数，CloudBase PostgreSQL 与私有 pgstore 图片桶。浏览器只调用同域 `/api`，云凭据仅放在自己的云函数运行配置中。

需要 Node.js 22.13 或更高版本。安装依赖和构建：

```sh
npm ci --ignore-scripts
npm test
npm run check:privacy
npm run build
```

输出为 `dist/public/`（网页）和 `dist/cloudfunctions/our-days-api/`（云函数）。**构建不会上传或发布到云端。** 此项目有服务端权限检查，不能仅通过 GitHub Pages 静态托管获得完整功能。

## 部署你自己的版本

按照 [CloudBase 部署指南](docs/DEPLOYMENT.md)，使用你自己新建的环境、数据库、存储、会话密钥和初始化令牌。未配置自己的环境时，后端会拒绝启动。

公开的两地时间显示设置在 `src/site-config.ts`。默认是中国时间与 UTC 示例；可改成自己的 IANA 时区和标签。**不要把密码、进入链接或云凭据填到前端文件。**

## 如何保持与其他实例隔离

1. 创建自己的新云环境，不复用任何人的数据库或照片桶。
2. 生成自己的 `SESSION_SECRET`、`BOOTSTRAP_TOKEN` 和服务端 API Key。
3. 配置自己的站点域名及 `/api` 同域路由。
4. 首次部署后用自己的初始化链接设置管理员密码，再为自己的家人生成新链接。
5. 不复制其他实例的密码哈希、成员表、照片、会话密钥或备份。

仓库没有自动部署任务。GitHub Actions 只运行测试、隐私检查与构建，不接触云环境。
